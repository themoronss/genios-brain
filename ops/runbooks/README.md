# Runbooks

One doc per incident scenario. Each follows the same 4-section shape:

- **Trigger** — the symptom that brought you here
- **Diagnosis** — how to confirm the root cause
- **Mitigation** — what to do right now
- **Follow-up** — what to fix permanently afterwards

Tool-agnostic by default (observability stack is deferred — see
[PHASE_DEVIATIONS.md](../../PHASE_DEVIATIONS.md) item R).
When Grafana Cloud / alerting ships, add links to specific dashboards.
