# Lifecycle, edge cases and gaps

The backend route is active, but no complete browser-extension bundle, installation/update flow,
browser-store packaging, site permission model or CRM/email integration code is present here.

Expired presence is ignored, and missing extension presence falls back to another human route
rather than inventing context. Delivery means inbox availability, not DOM injection or view. A
presence change can refresh a safely mutable queued route; ambiguous or already-delivered attempt
evidence prevents automatic mutation.
