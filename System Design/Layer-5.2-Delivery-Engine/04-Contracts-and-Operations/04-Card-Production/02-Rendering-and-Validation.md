# Rendering and validation

A bounded temperature-zero model call may improve wording only. The renderer receives typed slots rather than unrestricted database context. Deterministic validators check length and invention against the allowed fact corpus; validation failure returns the raw deterministic slot rendering.

Rendering cannot change evidence, execution identity, priority, recipient, route, admission policy or state. Those are resolved by authoritative deterministic components and persisted outside the generated prose.

Provider-specific delivery formatting can be regenerated when a fallback route advances, but it must still originate from the stored source payload and the newly selected format. Corrupt source prevents fallback rather than encouraging an invented message.
