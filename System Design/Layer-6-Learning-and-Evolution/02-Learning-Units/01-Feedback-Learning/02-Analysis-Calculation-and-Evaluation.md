# Analyzer, Calculator and Evaluator

## Analyzer / Calculator

Accepted/executed/run-play/do-it-myself count positive; rejected/cancelled/wrong count negative; every other explicit action stays neutral. Confidence is integer basis points.

## Evaluator

The evaluator emits even neutral metrics but governance still applies repetition, days, confidence/noise/conflict, freshness and value.

All counts, thresholds and rates are deterministic integers with explicit observation time.
