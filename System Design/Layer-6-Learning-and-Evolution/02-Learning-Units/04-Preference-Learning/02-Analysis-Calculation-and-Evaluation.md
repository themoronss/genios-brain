# Analyzer, Calculator and Evaluator

## Analyzer / Calculator

Repeated equal scope/key/value facts form evidence. User scope resolves to Behavior; non-user scope resolves to Organization.

## Evaluator

Conflicting values remain separate candidates/evidence rather than last-write-wins guesswork. Governance handles thresholds and review.

All counts, thresholds and rates are deterministic integers with explicit observation time.
