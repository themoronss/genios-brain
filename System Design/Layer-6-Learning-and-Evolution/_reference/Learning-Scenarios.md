# Learning scenarios

## Successful recommendation with low attention cost

Repeated succeeded outcomes for one capability/play produce Recommendation Learning evidence.
After thresholds/governance, an Adaptive efficacy entry may publish. Today it remains durable and
visible; no lower runtime automatically changes behavior from the generic entry.

## Completed but unproven

The unit retains the outcome as neutral. It can contribute to attention/progress analysis but
cannot inflate success precision.

## Temporary explicit memory

An authenticated user writes an explicit memory with a future expiry. Governance enforces maximum
TTL; publication enters Runtime memory. Expiry runs before weekly processing. No permanent brain
promotion is allowed.

## Organization-wide pattern

Repeated normalized subject+kind facts across distinct days can propose an Organization entry.
Default governance routes it to human review. Approval versions/publishes it; lower-layer generic
consumption remains absent.

## Knowledge drift

At least eight labeled outcomes with sustained success below the guarded threshold can create a
knowledge suggestion. A human may review it; the system does not edit Expert Brain or open a Git PR.
