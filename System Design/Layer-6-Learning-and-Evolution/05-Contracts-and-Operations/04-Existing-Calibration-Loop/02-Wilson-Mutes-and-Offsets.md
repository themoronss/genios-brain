# Wilson bounds, mutes and offsets

Wilson lower bounds protect small samples. Persistently weak rules may enter audited
`rule_mutes`. Bounded weekly/total offsets update `lvl3_config.rule_offsets` while honoring pins.

The exact tenant-pack row is the serialization lock; run claim, mutes, guarded authority-revision
update, nudge ledger and affected signal/card closure share the transaction. These outputs are read
by Reasoning as data, preserving the layer import law. No language model chooses a mute, threshold
direction or offset.
