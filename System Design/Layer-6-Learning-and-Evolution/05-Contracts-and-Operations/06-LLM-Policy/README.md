# LLM Policy

Layer 6 follows the product rule: language understanding may use AI; learning decisions remain
deterministic policy and arithmetic. The current Layer 6 implementation makes no LLM call. Any
future model seam belongs before typed learning facts and cannot bypass contract, ACL, lineage,
validation, governance or review.
