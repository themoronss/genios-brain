# Analyzer, Calculator and Evaluator

## Analyzer / Calculator

Delivered and actual failed/failed-terminal form the terminal denominator. Queued/suppressed/other work remains open_or_suppressed. P50 latency uses recorded delivered rows.

## Evaluator

Deferrals count attention/timing behavior but not provider failure. All rates use integer basis points.

All counts, thresholds and rates are deterministic integers with explicit observation time.
