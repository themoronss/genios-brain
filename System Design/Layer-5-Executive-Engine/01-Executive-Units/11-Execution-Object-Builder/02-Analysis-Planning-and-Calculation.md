# Analyzer, Planner and Calculator

## Analyzer / Planner

The analyzer composes canonical tuples and hashes. Calculators derive stable plan/execution identity using integer/time-safe values.

## Calculator

Excluding routing from identity makes reassignment an audited update instead of a duplicate commitment.

## Determinism

The same frozen input and evaluation time produce the same result. Ordering, ties and thresholds
are explicit in code and are covered by focused tests; an LLM is not an alternate execution path.
