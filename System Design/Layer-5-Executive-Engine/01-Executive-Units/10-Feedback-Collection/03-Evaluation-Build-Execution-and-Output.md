# Evaluator, Builder, Executor and Output

## Evaluator / Builder

The evaluator builds one immutable outcome and prevents duplicate reinterpretation. The store exposes it to the learning batch.

## Executor / Output

Atlas Layer 6 maps positive, negative and neutral classes explicitly; this unit does not mutate a brain.

## Failure posture

A rejected or incomplete input returns a typed, auditable result. The unit does not silently skip
an invariant and does not upgrade uncertainty into authority.
