# Analyzer, Planner and Calculator

## Analyzer / Planner

Due rungs are calculated from the frozen ladder, creation/deadline clocks and recorded history. `next` is deterministic and idempotent.

## Calculator

A reporting-line change can reroute the recipient without rewriting the original commitment.

## Determinism

The same frozen input and evaluation time produce the same result. Ordering, ties and thresholds
are explicit in code and are covered by focused tests; an LLM is not an alternate execution path.
