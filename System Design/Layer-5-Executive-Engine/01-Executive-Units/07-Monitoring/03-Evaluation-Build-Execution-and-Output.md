# Evaluator, Builder, Executor and Output

## Evaluator / Builder

The evaluator recommends a legal lifecycle move. The output preserves both progress and uncertainty for tracking and feedback.

## Executor / Output

Monitoring emits no user communication itself; Reminder/Escalation decide attention, and Delivery transports.

## Failure posture

A rejected or incomplete input returns a typed, auditable result. The unit does not silently skip
an invariant and does not upgrade uncertainty into authority.
