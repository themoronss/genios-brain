# Analyzer, Planner and Calculator

## Analyzer / Planner

Communication scoring maps urgency, confidence and business audience into a band, tone,
presentation intent and backwards-compatible route hints. Reassignment preserves commitment
identity. The actual channel and interrupt flag are recomputed by Layer 5.2 from live context and
policy; these frozen v1 values cannot bypass that boundary.

## Calculator

The interruption decision is a budget on human attention, not a claim that a provider is online.

## Determinism

The same frozen input and evaluation time produce the same result. Ordering, ties and thresholds
are explicit in code and are covered by focused tests; an LLM is not an alternate execution path.
