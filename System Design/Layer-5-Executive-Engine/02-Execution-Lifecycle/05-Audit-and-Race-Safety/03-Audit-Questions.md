# Audit questions this layer can answer

- Why was the commitment created, and from which decision/play version?
- Who owned it at each outbound moment?
- Which action/dependency blocked progress?
- Why was a reminder suppressed, rerouted or delivered?
- What changed the state, by which actor, and at what explicit time?
- Which evidence supported the terminal outcome?

If one of these cannot be answered from persisted data, production proof is incomplete.
