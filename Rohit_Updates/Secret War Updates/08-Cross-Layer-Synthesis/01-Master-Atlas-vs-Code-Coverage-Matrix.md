# Master Atlas-vs-Code Operational Coverage Matrix

## Evidence boundary and blunt verdict

This matrix synthesizes the seven layer audits against `harsh/mvp@b739bd5ca682d09550acc400ed2892c38c8518f8` on 2026-08-22. **[ATLAS]** is expected architecture; **[CODE]** is inspected implementation; **[TEST]** is a named deterministic run; **[SCREENSHOT]** proves only a rendered symptom; **[CUSTOMER]** is the demanded result. The target documentation branch is not runtime evidence.

The statuses are intentionally not collapsed:

- **Absent**: no current artifact/behavior was found.
- **Stub**: a shape or fail-closed placeholder exists without meaningful complete behavior.
- **Present**: real implementation or content exists, but reachability is not implied.
- **Wired**: producer hands the artifact to its declared consumer.
- **Live**: the evaluated runtime path uses it; where only screenshots support this, the cell says “surface observed” and does not infer commit parity.
- **Tested**: a fresh named deterministic check passed; a skip is not a pass.
- **Outcome-proven**: a verified business result with action, completion, outcome window, attribution and counterfactual exists.

**System verdict: framework-rich, not customer-intelligence-ready.** Strong deterministic machinery exists in every layer, but the authoritative vertical chain is split: Layer 1 does not emit the full roleful/permission-carrying Atlas signal; Layer 2 can hand over person-wide or semantically incomplete context; Layer 3’s deep compiler is default-off/shadow and the corpus is mostly stubbed with **zero reviewed or accepted** capabilities; Layer 4’s active adapter supplies thin candidates, gives three runtime brains hash-only influence, and loses critical fields in projection; Layer 5’s real ExecutionObject is not welded to visible card acceptance/agent action; Layer 6 runs a safer legacy sender while stronger v2 remains non-canonical; Layer 7 has an approval-to-publish break, lossy policy loading and an unrepresentable Adaptive expiry contract. **No layer is Outcome-proven from supplied evidence.**

## Decision

Do not activate everything together. The critical path is vertical and conjunctive: (1) roleful/permissioned QES, (2) bounded/version-fenced BSO, (3) one reviewed/accepted expertise lane with review-state admission and authoritative abstention, (4) complete DecisionObject, semantic brain-mutation proof and lossless card, (5) card-execution/action weld, (6) canonical fenced DeliveryResult, and (7) reconciled learning with review-to-publish, policy-load fidelity, representable lifecycle, safe rollback and demonstrated decision effect. Each promotion must be scoped by tenant + situation + capability/version, shadow-compared against labelled truth, and reversible.

The matrix is deliberately conservative: **Present** code is real engineering value; **Wired** code proves reachability; a screenshot may prove a **Live** surface symptom; **Tested** fixtures prove bounded behavior. None of those establishes **Outcome-proven** intelligence. That final state requires the founder to receive a materially correct recommendation, act through the accountable chain, obtain a verified result inside a declared window, and show credible attribution versus what would otherwise have happened.
