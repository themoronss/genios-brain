## Improvement strategy

Do not attempt a “complete all YAML, flip flag” launch. Build a small, deep, measurable **promotion lane**: one customer scenario → one accepted BSO contract → one authored capability dependency closure → **review-state admission bound to exact hashes** → one reproducible four-brain package with proved **semantic influence** → Layer 4 golden decision → shadow comparison → scoped authority → verified outcome. Scale only by repeating this lane.

The first promoted scope should target costly shown failures, not the easiest corpus files: role-safe warm introductions, scheduling/open-question resolution, verified meeting follow-up, and silence/cadence with explicit stop rules. Theresa/Antler must remain unsupported until investor/fundraising expertise is explicitly authored or mapped by an accepted domain decision; it must not be called ordinary Sales by convenience.

## Promotion sequence

1. Freeze emitted-situation inventory and blocking warning classes at the pinned corpus commit.
2. Choose one customer scenario lane and author its complete transitive expertise closure.
3. Apply review-state admission: named expert accepts the exact version/content hashes; any later byte change revokes admission.
4. Add deterministic negative, mutation and HKS fixtures before enabling authority.
5. Run compiler and four-brain snapshot replay; require identical canonical output, then run paired-snapshot metamorphic tests proving each decision-relevant brain entry’s semantic influence.
6. Feed the accepted package into Layer 4 and compare against legacy on labelled outcomes.
7. Enable for a bounded tenant/cohort key with kill switch and immutable package, admission and authority receipts.
8. Reconcile action, completion and business outcome before expanding coverage.

## Exit gate

Layer 3 becomes **conditionally trustworthy** only for a named promoted scope when: every required capability is non-stub, reviewed/accepted and bound to the exact admitted hash; every input situation routes to an accepted closure or explicitly abstains; role and visibility mutation tests are green; four-brain resolution is reproducible; every selected decision-relevant brain entry has proved semantic influence or explicit unused status; no runtime LLM owns route/policy/playbook selection; legacy cannot override abstention; the authoritative card carries package/snapshot/admission receipts; and scoped shadow/golden evaluation shows no critical regression. All other domains and situations remain explicitly unsupported or shadow. “46 files present,” “`stub:false`,” and “hash changed” are never an Exit gate.
