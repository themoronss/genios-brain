# Layer 1 — Knowledge: Loopholes, Edge Cases, and Fail-Closed Rules

## Reading rule

A **Loophole** is a path that can satisfy today’s checks while violating the intended guarantee. An **Edge case** is a legitimate data shape the product must handle. Neither is automatically an observed production failure. Current protections are labelled separately from proposed controls; a contract or unit test is not evidence that the protection is Wired and Live end to end.

Layer 1 must prefer recoverable uncertainty over silent evidence loss. “Fail closed” here usually means park, quarantine, suppress publication, or mark coverage incomplete—not delete the evidence and not fabricate an answer.

## Fail-closed decision ladder

| Condition | Allowed result | Forbidden result |
|---|---|---|
| Certain deterministic noise with retained audit policy | Drop plus reason/receipt | Silent deletion with no challenge path |
| Ambiguous business relevance | Park/review or keep with low rank | Confident destructive drop from uncalibrated model |
| Unsupported/failed content extraction | Park and retry/review | Emit an “empty” signal as if no request exists |
| Unknown source visibility or use restriction | Suppress publication and request scope | Default to org visibility |
| Unknown role/business subject | Emit transport facts plus role uncertainty | Treat sender/connector as prospect by default |
| Incomplete source coverage | Mark predicate unknown | Infer no reply/no meeting/no usage |
| Versionless mutable object | Quarantine mapping/version issue | Dedup forever as immutable |
| Conflicting canon or correction | Preserve both, flag conflict, recompute after authority resolution | Last-write-wins without evidence |

## Priority

The first production blockers are L1-01 visibility propagation, L1-02 roleful thread capture, L1-03 destructive model-drop recovery, L1-06 mutable version enforcement, and L1-17 scoped completeness. They directly determine whether downstream intelligence is grounded in the right evidence. Optimizing embeddings or connector count before these guarantees would make unsafe decisions faster, not smarter.
