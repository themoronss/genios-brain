# Layer 2 — Loopholes, Edge Cases and Fail-Closed Behavior

## Boundary rule

A **Loophole** formally passes today’s schema/rule while violating the customer guarantee. An **Edge case** is a legitimate business shape that the system must represent. “Fail closed” at Layer 2 means preserve evidence/history, emit a bounded observation with explicit missing/conflict codes, and withhold prescriptive authority; it does **not** mean delete the signal or silently return no result. The Consequence column describes the harm if downstream expertise treats incomplete context as current truth.

This catalog is **[CODE]** evidence at `harsh/mvp@b739bd5` plus **[MODELLED]** adversarial scenarios. The focused Layer 2 suite is Tested (214 passed), while Live incidence and Outcome impact remain Unknown unless a row cites supplied screenshot symptoms. Every safe result must retain an audit receipt and recovery path.

## Universal fail-closed envelope

Every incomplete Layer 2 handoff should contain: immutable input/signal IDs; graph, selector, domain-spec and extractor versions; source/field evidence receipts; role candidates; current-state/conflict vector; source readiness windows; visibility and permitted-use intersection; exact `missing_context_codes`; one of `observation_only`, `review_source`, `split_required`, `suppressed_policy`, or `ready_for_expertise`; and a recovery trigger. It must not include an action button when target, unresolved object or allowed use is unknown.

## Exit gate

No prescriptive production authority until the complete HKS/adversarial corpus shows: zero connector-as-target errors; zero cross-role/deal leakage; zero visibility widening; zero synthetic-evidence authorization; 100% abstention on required-role/current-state ambiguity; correct completion isolation across channels; and version-fenced recovery after correction/outage. Metrics must be cohort-labelled and compared with human review. A skip, an observation-only result, and a safely split situation are not failures; silent merge, fabricated certainty and unrecoverable suppression are.
